# Security

Vera is published as-is and isn't actively maintained, but security reports are still welcome.

Please report vulnerabilities privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Don't open a public issue.

If you run Vera yourself, you're responsible for your own deployment: keep the engine behind HTTPS, use a long random `API_SECRET_KEY`, keep two-factor login on, and keep your provider keys and Supabase secret key out of version control.
